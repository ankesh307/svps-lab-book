Class 2: Fun with Electronics & Mechanics
(No Screens)
1. Battery Magic: Connect a 9V battery to wires and turn on your first LED.
2. The Circuit Path: Learn how a broken wire turns the light off (Open/Close circuit).
3. Switch Control: Add a Rocker Switch to turn the light ON and OFF easily.
4. Doorbell Alarm: Connect a Push Button and a Buzzer to make a doorbell.
5. Conductor Test: Test wood, plastic, and metal to see which one lets electricity
pass.
6. Series Lights: Connect 2 LEDs in one line (like Diwali lights).
7. Parallel Lights: Connect 2 LEDs on different paths (like house wiring).
8. Mini Table Fan: Attach a propeller to the normal toy motor to make a fan.
9. Reverse Air: Swap the motor wires to make the fan blow air backwards.
10. Gear Motor Intro: Attach wheels to your heavy gear motor. See how strong it is!
11. Power Test: Compare the fast toy motor vs. the strong, slow gear motor.
12. Vibration Magic: Turn on the coin motor to feel it vibrate like a mobile phone.
13. Bristlebot (Part 1): Stick the vibration motor on a brush to make a moving bug.
14. Bristlebot (Part 2): Add weight to the bug to make it turn left or right.
15. Traffic Lights: Use 3 switches to manually control Red, Yellow, and Green LEDs.
16. Magic Wand: Connect 5 colorful LEDs together to make a glowing wand.
17. Wire Maze Game: Build a game where touching a bent wire sounds a buzzer
alarm.
18. Scrap Switch: Make your own working switch using cardboard and a paperclip.
19. Security Box: Make a box that rings an alarm buzzer as soon as you open it.
20. Air Thrust Car: Build a car that moves forward using the wind from your fan
motor.
21. Forward/Reverse Car: Use special switch wiring to make your 1-Motor car go
forward and backward.
22. Smart Home Craft 1: Build a 2-room house using cardboard and craft sticks.
23. Smart Home Craft 2: Put real LED lights and hidden wires inside your cardboard
house.
24. Smart Home Craft 3: Add a roof exhaust fan and a front doorbell to the house.
25. Wire Resistance: Use a very long wire and watch the LED light become dim.
26. Water Power Test: Put wires in water and add salt to see the electricity flow.
27. AND Logic Game: Wire it so the buzzer only rings if you press two buttons at
once.

Class 6: Wi-Fi Bots, Python & 3D
Fabrication
1. Meet ESP8266: Learn about the Wi-Fi board and its 3.3V power limit.
2. Install Board Software: Add the ESP8266 support files into the Arduino IDE.
3. Connect to Wi-Fi: Write code with your network password to connect the board
to Wi-Fi.
4. Find IP Address: Ping the network to find the secret IP address of your board.
5. Local Web Server: Write HTML code inside your C++ script to make a mini-
website.
6. Web Switch: Open the website on your phone and tap a button to turn on the lab
lights.
7. Python Basics: Open Python on the PC and run simple print and math
commands.
8. Python Loops: Use While True and If-Else loops inside Python.
9. Python + Arduino: Read the live sensor data from the board directly into the
Python screen.
10. Measure for 3D: Use a digital caliper ruler to measure a sensor for a custom 3D
case.
11. Bambu Slicer Software: Put a 3D model into Bambu Studio to prepare it for
printing.
12. Slicing Settings: Set the "Infill" to Gyroid so the part prints strong but lightweight.
13. Print a 3D Part: Load the plastic filament and watch the Bambu Lab printer make
your part.
14. L298N Motor Driver: Learn how this big red board handles high power for the
Car motors.
15. Battery Split Wiring: Safely share the battery power between the L298N and the
Wi-Fi board.
16. C++ Car Code: Write functions to make the L298N drive the car forward,
backward, left, right.
17. Ultrasonic Radar: Learn how the sensor uses bat-like sound echoes to measure
distance.
18. Distance Math: Write the math formula to turn sound time into Centimeters.
