## Theory (20 Minutes)

### How Vibration Motors Work
Vibration motor ek special DC motor hai jisme ek UNBALANCED weight (eccentric mass) hota hai shaft par.

```
Normal Motor:              Vibration Motor:
  Shaft rotates             Shaft rotates
  Balanced → No vibration   UNBALANCED WEIGHT → VIBRATION!
```

**Eccentric Mass Effect:**
```
        [Weight]
       /
[Motor Shaft]  → spins fast → creates imbalance → VIBRATES!
```

**Real-World Uses:**
- 📱 Smartphone silent mode vibration
- 🎮 Game controller rumble (haptic feedback)
- ⌚ Smartwatch notifications
- 🔔 Pager alerts

## Practical Lab (45 Minutes)

### Components:
- 9V Battery (or 3.7V LiPo — better for coin motor)
- Coin Vibration Motor (flat circular)
- Push Button
- Jumper Wires

### Wiring:
```
Battery(+) → Push Button → Motor Red Wire
Motor Black Wire → Battery(−)
```

### Experiments:
1. **Basic Test**: Press button → Feel the vibration!
2. **Surface Test**: Place vibrating motor on:
   - Metal surface — what sound?
   - Wood surface — what sound?
   - Cardboard — what sound?
3. **Bristlebot Preview**: Tape to a toothbrush head — it moves!

### Fun Fact:
Your phone's vibration motor is EXACTLY the same type — just smaller!
