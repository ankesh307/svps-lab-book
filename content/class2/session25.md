## Theory (20 Minutes)

### What is Resistance?
Resistance = Bijli ke flow mein obstacle (rukaawat)

**Unit:** Ohm (Ω) — named after Georg Simon Ohm

**OHM's LAW:**
```
V = I × R
Voltage = Current × Resistance
```

**Long Wire = More Resistance:**
```
Short wire: Low resistance → More current → Bright LED
Long wire: High resistance → Less current → DIM LED
```

**Why Thin Wire has More Resistance:**
```
Thick pipe: More water flows (less resistance)
Thin pipe: Less water flows (more resistance)

Same for electricity! Thin wire = High resistance
```

**Real-World Effect:**
Long distance power transmission lines → Resistance increases → Voltage drops
That's why power companies use HIGH voltage (220V, 33kV, 132kV) for long distance!

## Practical Lab (45 Minutes)

### Experiment: Long Wire, Dim Light!

### Materials:
- 9V Battery
- LED + 220Ω Resistor
- Normal short wires (30cm) — Part A
- Very long wire (3-5 meters) — Part B

### Experiment:
**Part A — Short Wire:**
```
Battery → Short Wire (30cm) → LED → Battery
Observe LED brightness: BRIGHT!
```

**Part B — Long Wire:**
```
Battery → Very Long Wire (5m) → LED → Battery
Observe LED brightness: DIM!
```

### Measurement (if multimeter available):
Measure current in both cases. Record in table:
| Wire Length | LED Brightness | Current (approx) |
|---|---|---|
| 30 cm | | |
| 5 meters | | |

### Analysis:
More wire length → More resistance → Less current → Dimmer LED!
This proves Ohm's Law!
