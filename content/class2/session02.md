## Theory (20 Minutes)

### Open vs Closed Circuit
**Closed Circuit**: Current ka poora path hota hai → Light jalta hai
**Open Circuit**: Path mein koi break hai → Light nahi jalta

```
CLOSED CIRCUIT:          OPEN CIRCUIT:
Battery → Wire → LED    Battery → Wire → X → LED
  ↑                                      (Break!)
Current flows!          Current STOPS!
```

**Real Life Example**: Switch dabao → circuit close → light jale. Switch choro → circuit open → light band!

**Analogy**: Socho bijli ek pipe mein paani ki tarah hai. Pipe toot gayi → paani nahi bahega!

## Practical Lab (45 Minutes)

### Activity: Make & Break the Circuit!

**Components:**
- 9V Battery + Snap
- 2 LEDs, 2 Resistors (220Ω)
- Jumper Wires

**Experiment 1 — Closed Circuit:**
```
Battery(+) → Resistor → LED(+) → LED(−) → Battery(−)
Result: LED JALTA HAI!
```

**Experiment 2 — Open Circuit:**
Remove any one wire and observe.
```
Battery(+) → Resistor → LED(+) → [GAP] → Battery(−)
Result: LED BAND HO JAATA HAI!
```

**Experiment 3 — Find the Break:**
Teacher will secretly remove a wire. Students must find which wire is broken!

## Quiz (5 Minutes)

**Q1.** Open circuit mein kya hota hai?
> Answer: Circuit mein break hoti hai, current flow nahi karta

**Q2.** Switch circuit ke saath kya karta hai?
> Answer: Close ya Open karta hai — current flow control karta hai

**Q3.** Real life mein open circuit ka ek example do?
> Answer: Fused bulb, broken wire, ya open switch
