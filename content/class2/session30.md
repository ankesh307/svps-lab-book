## Theory (20 Minutes)

### Engineering Showcase — Why It Matters
Real engineers apna kaam SHOWCASE karte hain:
- Science fairs
- Product launches
- Tech conferences (CES, Google I/O)
- Patent presentations

**Aaj Tumhara Showcase:**
Tumne is mahine jo seekha woh duniya ko dikhao!

**Projects to Show:**
1. Smart Home (LED + Fan + Doorbell)
2. Air Thrust Car / Bristlebot
3. Logic Gates Game (AND / OR)
4. Wire Maze Game
5. Any personal project

**Judge Criteria:**
- Functionality: Kaam kar raha hai?
- Explanation: Samjha sakte ho?
- Creativity: Kuch unique?
- Presentation: Clear aur confident?

**Celebrate!** Har student ek junior engineer hai!

## Common Problems & Fixes

| Problem | Solution |
|:---|:---|
| Nothing working | Check power connections first |
| Incorrect output | Verify wiring against diagram |
| Code not uploading | Check COM port and board selection |
| Unexpected values | Check sensor connections |
