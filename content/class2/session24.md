## Theory (20 Minutes)

### Ventilation and Exhaust Systems
**Why Exhaust Fan?**
Kitchen mein khana pakane se:
- Heat increases
- Smoke/steam generated
- Carbon dioxide levels rise
Exhaust fan → fresh air in, stale air out!

**Doorbell System:**
Real doorbell → Wireless signal → Indoor chime
Ours: Button press → Buzzer beep (same concept!)

**Complete Smart Home Features so far:**
| Room | Features |
|---|---|
| Bedroom | LED ceiling light + switch |
| Kitchen | LED light + Exhaust fan motor |
| Entrance | Doorbell button + buzzer |
| Roof | Exhaust fan motor |

## Practical Lab (45 Minutes)

### Add Fan + Doorbell!

### New Components:
- Toy motor + Propeller (exhaust fan)
- Push Button (doorbell)
- Active Buzzer (doorbell chime)

### Fan Wiring (Roof):
```
Battery (+) → Fan Switch → Motor (+) (Red)
Motor (−) (Black) → Battery (−)
```
Motor ko roof mein cut kare hole ke andar lagao — propeller upward face kare!

### Doorbell Wiring:
```
Battery (+) → Doorbell Button (front door) → Buzzer (+)
Buzzer (−) → Battery (−)
```
Button front door ke bahar lagao, buzzer andar bedroom mein!
